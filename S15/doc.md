# Сервис 15: Load Assignment Service (Сервис распределения нагрузки)

## Функционал сервиса
- Добавить Assignment
- Изменить Assignment по ID
- Удаление Assignment по ID
- Получить Assignment по ID
- Получить список Assignment по заданным параметрам
- Добавить Teacher
- Добавить Discipline
- Добавить Group
- Связать Teacher и Discipline (TeacherDiscipline)

## Добавить Assignment
Информация требуемая для создания Assignment представлена в виде таблицы со столбцами:

| Параметр | Обязательность | Тип | Ограничение | Значение по умолчанию | Пояснение |
|---|---|---|---|---|---|
| teacher_discipline_id | Да | Integer | > 0, внешний ключ | - | ID связи преподавателя с дисциплиной |
| group_id | Да | Integer | > 0, внешний ключ | - | ID группы, в которой ведётся дисциплина |
| semester | Да | String | Не пустой | - | Название семестра (например, "Осень 2025") |
| hours | Да | Integer | >= 0 | - | Количество часов нагрузки в семестре |

Перечислить уникальные комбинации параметров, если есть:
Уникальная комбинация `(teacher_discipline_id, group_id, semester)` — один преподаватель не может вести одну дисциплину в одной группе дважды за семестр.

Информация возвращаемая в случае удачного создания Assignment и представлена в виде таблицы со столбцами:

| Параметр | Тип | Пояснение |
|---|---|---|
| id | Integer | Уникальный идентификатор назначения |
| teacher_discipline_id | Integer | ID связи преподавателя с дисциплиной |
| group_id | Integer | ID группы |
| semester | String | Семестр |
| hours | Integer | Количество часов |
| created_at | DateTime | Дата и время создания записи |

## Получить список Assignment по заданным параметрам
Информация требуемая для получения списка Assignment представлена в виде таблицы со столбцами:

| Параметр | Тип | Описание | Пояснение |
|---|---|---|---|
| teacher_id | Integer | Фильтрация по ID преподавателя | Находит все назначения для конкретного преподавателя |
| discipline_id | Integer | Фильтрация по ID дисциплины | Находит все назначения для конкретной дисциплины |
| group_id | Integer | Фильтрация по ID группы | Находит все назначения для конкретной группы |
| semester | String | Фильтрация по семестру | Находит назначения за конкретный семестр |
| hours_min | Integer | Минимальное количество часов | Фильтр по нижней границе часов нагрузки |
| hours_max | Integer | Максимальное количество часов | Фильтр по верхней границе часов нагрузки |
| limit | Integer | Количество записей в ответе | По умолчанию 50 |
| offset | Integer | Смещение для пагинации | По умолчанию 0 |

Информация возвращается в виде списка Assignment и представлена в виде таблицы со столбцами:
